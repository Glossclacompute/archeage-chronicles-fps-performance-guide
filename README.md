## 📁 How It Works

1. Record your display resolution, refresh rate, graphics preset and frame-rate cap.
2. Launch the game and test the same scene for two minutes; note average FPS and the moments when stutter appears.
3. Check GPU utilization, VRAM pressure and temperature in your preferred Windows monitoring application.
4. Lower one expensive graphics option at a time, retest, then revert changes that do not help.
5. If FPS remains unchanged while GPU usage stays low, investigate CPU load and background applications.
6. If visuals are smooth but movement feels delayed, use the connection diagnostics guide rather than lowering graphics.
